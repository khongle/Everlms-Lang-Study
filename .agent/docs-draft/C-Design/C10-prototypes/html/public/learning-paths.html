Common questions about learning paths

Do I need to be a subscriber to start a path?

The first course in every learning path is available to free accounts as a preview. Full path access requires a Pro subscription or individual course purchases.

Can I skip courses I already know?

Yes. Take the skill assessment at the start of each course; if you score 80%+, that course is marked complete and you advance to the next one.

How long does a path take to complete?

At 1 hour/day, most paths take 3–6 months. At 3 hours/day you can complete a 120-hour path in roughly 6 weeks. All paths are self-paced — no deadlines.
