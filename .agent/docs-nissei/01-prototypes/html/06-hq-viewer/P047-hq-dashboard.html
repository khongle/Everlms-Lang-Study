Scope rule made visibleHQ Viewer is a deliberately separate role from HR/HSE Central, not a cut-down copy of it. HQ needs full visibility to sponsor the project from Hamamatsu, but has no day-to-day operational need to assign training, edit the matrix, issue certificates, or send reminders.
