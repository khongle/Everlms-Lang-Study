Check the number for typing errors. Certificate numbers use the format branch code, issue year, employee code, course code. If the number is correct and this still fails, the certificate may have been revoked and reissued under a new number, or it may not have been entered into the system yet. Contact the site training manager for the branch shown on the certificate.

Prototype noteThis page shows only what an inspector or auditor needs to confirm authenticity: holder name, course, issue date and expiry date. It never shows date of birth, home address, phone number, salary, or the employee’s full training history. That minimal-PII rule is deliberate: this is the one page in the system that anyone can open without an account, so it discloses the least amount of personal data that still proves the certificate is real, consistent with data minimisation under Decree 13/2023 (Vietnam) and PIPL (China).
