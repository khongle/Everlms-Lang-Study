Fallback rule

If a UI string is missing in the active language, the interface falls back to English, never to a blank label. English is the source language and is always 100% complete by definition.

Content vs. interface

This page covers the interface chrome only: buttons, labels, navigation. Course content translation (lessons, quizzes, certificates) is tracked separately and pinned to a source version at the translation workspace, owned by HR/HSE Central.

Adding a fifth languageA new UI language is translation work, not architecture work: it means filling in the missing rows in the table above until progress reaches a publishable threshold. No route, table or permission changes are required to enable it.
