CJK font requirement for PDF generation

Certificates are rendered to PDF with mPDF. The default Latin font cannot draw Japanese glyphs. Without an embedded CJK-capable font, the Japanese side prints as empty boxes (tofu). Font profile: Noto Sans JP Regular, embedded at PDF build time. This is a build dependency, not a template setting, and must be verified on every server that generates certificates.

Why bilingual, on every certificateEvery certificate is Vietnamese and Japanese on the same PDF, not two separate documents. Vietnamese is what the Decree 44/2016 labor inspector and the employee expect; Japanese is what Hamamatsu HQ (roles.txt hq_viewer) needs to review without translation. One template with two content blocks keeps both audiences on a single source of truth instead of a translated copy drifting out of sync.
