What happens to in-progress learners

  • Mid-course on v2.0 when v2.1 publishes finish their current attempt on v2.0; the result still counts.
  • New enrollments after publish start directly on v2.1.
  • Certificates already issued under v2.0 remain valid until their own expiry date; the next retraining cycle is taken on v2.1.
Central publishing rulePublishing is central, so every site receives the same version at the same time. There is no mechanism for NEV-HCM to keep running v2.0 while NEH-HAN moves to v2.1: that would mean two factories teaching two different chemical-handling standards under the same company. When v2.1 publishes, the translation workspace is notified and the existing Vietnamese and Chinese translations are marked stale (see P045).
