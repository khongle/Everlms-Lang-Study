Core, delta, data separation Every configuration item on this environment sits in exactly one of three places: CORE (part of the product release, identical for every customer), DELTA (Nissei’s own configuration, tracked and exportable), or, when something goes wrong, drifted from both. This separation is what keeps Nissei upgradable: a release can be applied because it only ever touches CORE, Nissei’s DELTA reapplies cleanly on top, and DATA (employees, training records) is never part of a release at all. The one drifted item above is the exception that proves why this page has to exist: without it, that hand-patched certificate template would silently diverge further from the next release until something broke in a way nobody could explain.
