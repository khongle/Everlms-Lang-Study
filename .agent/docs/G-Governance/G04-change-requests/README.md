## When a CR is needed
- Editing code outside the current story's scope.
- Structural changes to `.agent/docs/` (also update `A01-target-docs-structure.md` first — Structure Lock).
- Changing a canonical ID/path or a mirror pair.

Template: `CR-NNN-<slug>.md` — what/why, scope, impact ([E09](../../E-Quality/E09-impact-analysis/README.md)), approval.
