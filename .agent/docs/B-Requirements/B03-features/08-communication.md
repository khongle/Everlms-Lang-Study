# Feature: Communication & Community

## 1. Tổng quan

Tạo hệ sinh thái giao tiếp giữa learner, instructor, và admin. Bao gồm: notifications, forum, comments, rating, và FAQ.

---

## 2. Notifications & Alerts

| # | Yêu cầu | Chi tiết |
|---|---------|---------|
| N-01 | In-app notifications | Notification bell icon với unread count |
| N-02 | Email notifications | Gửi email cho events quan trọng |
| N-03 | Notification types | Enrollment confirmation, quiz result, certificate issued, payment receipt, assignment deadline, new forum reply |
| N-04 | Notification preferences | User chọn nhận notification loại nào (email/in-app/both/none) |
| N-05 | Admin announcements | Broadcast notification tới tất cả users hoặc specific group |
| N-06 | Push notification (mobile) | Push notification cho mobile app |
| N-07 | Reminder notifications | Nhắc học viên quay lại học (inactive reminder) |

---

## 3. Forum & Discussion

| # | Yêu cầu | Chi tiết |
|---|---------|---------|
| FR-01 | Course forum | Mỗi course có forum riêng |
| FR-02 | Forum topics | Tạo topic/thread mới |
| FR-03 | Replies & threads | Trả lời, nested replies |
| FR-04 | Rich text | Formatted text, code blocks, images |
| FR-05 | Moderation | Flag/report, admin approve/delete |
| FR-06 | Search | Tìm kiếm trong forum |
| FR-07 | Pinned topics | Ghim topic quan trọng lên đầu |
| FR-08 | Notifications | Notify khi có reply trên topic đang follow |
| FR-09 | Forum categories | Phân loại topics theo chủ đề |
