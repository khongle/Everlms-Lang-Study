# F04-release-communications - Release Communications

Templates for announcing releases (internal + learner-facing).

## Internal release note (template)
> **EverLMS <version>** — <date>. Highlights: <features>. Fixes: <issues>. Migration: <steps/none>. Known issues: <P1/P2>. Rollback: H02.

## Learner-facing (template, editor-managed)
> Published as a blog article ([F-016](../../B-Requirements/B03-features/F-016-blog-and-faq-content.md)) and an in-app notification ([F-017](../../B-Requirements/B03-features/F-017-notifications.md)). Keep copy in entity fields (no hardcoded text).

## Channels
- In-app notification broadcast ([P050](../../C-Design/C11-pages-components/pages/P050-notification-broadcast.md)).
- Email (once INT-008 complete).
- Blog/news post.

> First public release is gated on the P0 items in [F02](../F02-release-checklist/README.md).
