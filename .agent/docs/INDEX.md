# EverLMS — Documentation Index

> **EverLMS** là nền tảng Learning Management System (LMS) chuyên nghiệp, được xây dựng trên **Drupal 11 + PHP 8.3**.
> Sản phẩm hướng tới thị trường giáo dục trực tuyến B2B/B2C với khả năng mở rộng enterprise-grade.
