# M03-impact-templates - Impact Templates

Template for assessing a change before doing it (fill into [E09](../../E-Quality/E09-impact-analysis/README.md)).

```markdown
## Change: <what>
- Affected modules: <C05 links>
- Affected entities: <C04 links>
- Affected pages/API: <C11 P### / I01 endpoints>
- Cross-module side effects: <events, gateways, providers>
- Tests to run: <E03 defs / flows>
- Data/migration: <none | steps>
- Rollback: <steps / H02>
- Risk delta: <new/raised G02 rows>
```
