## Vision

EverLMS is a full-featured, enterprise-grade Learning Management System built on Drupal 11 (PHP 8.3, MariaDB 10.11). It targets the B2B/B2C online-education market in Vietnam and Southeast Asia, delivering structured course authorship (Course → Chapter → Lesson), automated assessment and grading, cascading progress tracking, integrated commerce (orders, memberships, bundles), AI-assisted content generation, live sessions via Zoom, certificate issuance with public verification, community features (forum, notes, ratings), rich analytics, and a native Flutter mobile companion app — all under a unified dark-premium design system.

---

## Scope

### In Scope

- **Content hierarchy:** Course → Chapter → Lesson (9 lesson types: video, text, quiz, h5p, scorm, pdf, pptx, zoom, mixed)
- **Assessment engine:** 8 question types (single_choice, multiple_choice, true_false, fill_blank, short_answer, essay, matching, ordering); `GradingStrategyFactory` static factory with per-type strategy classes; binary pass/fail; manual essay grading; `QuizPassedEvent` dispatch
- **Progress tracking:** Lesson → Chapter → Course cascade; `lms_user_lesson` / `lms_user_course` entities; `ProgressApiController` mark-complete API
- **Commerce:** Order management, coupon codes, membership plans (monthly/quarterly/yearly/lifetime), course bundles, Stripe (PaymentIntent), bank-transfer (VietQR); payment plugin system (`PaymentGatewayManager` + `@PaymentGateway` annotation)
- **Certificate issuance:** Auto-issued via event subscriber on `lms_quiz.passed`; PDF generated by mPDF; template designer (HTML/Twig layout, background, logo, seal, orientation); public verification endpoint
- **Community & communication:** Forum with threaded replies and best-answer marking; in-app notifications (10 event types); lesson notes with video timestamp; course ratings and reviews; FAQ
- **AI platform:** Drupal Plugin manager (`AiProviderManager`); OpenAI (GPT-4o) + Gemini (gemini-2.5-flash) full providers; Pollinations (image-only); AI course builder with queue worker; AI Engine admin wizard (multi-step: users, curriculum, courses, chapters, lessons, slides, SCORM, Google Slides, quizzes); Zoom agenda generation
- **Analytics & reporting:** Course, user, and quiz reports with CSV export; `lms_analytics` module (no GA4 dependency — internal DB queries only)
- **Zoom integration:** Server-to-Server OAuth; meeting lifecycle (create/update/delete via lesson save hook); Web SDK join page; JWT signature endpoint; AI-generated meeting summaries via cron
- **Theme system:** `lms_theme` (default, 15 switchable homepage skins, dark glassmorphism + 14 light/themed variants, Bootstrap 5.3.3 CDN); `lms_classic` (secondary, single skin); admin via `claro`
- **Mobile app:** Flutter app `app/` (v1.0.10+33, 33 screens, Riverpod/GoRouter/Dio); backend module `lms_mobile_api` serving `/api/v1/*`; custom bearer token auth (keyvalue.expirable + OTP); English + Vietnamese l10n; social auth (Google, Facebook, Apple, Microsoft MSAL)
- **User management:** 7 roles (anonymous, authenticated, student, instructor, manager, content_editor, administrator); social auth (oauth2 via drupal/social_auth_google + social_auth_facebook); password policy; user impersonation (`open_switcher`)
- **Config-driven infrastructure:** 396 YAML files in `/config/sync` (tracked in git); DDEV local dev (`everlms.ddev.site`); nginx-fpm; Drush 13.7.2

### Out of Scope

- Multi-tenant DB separation (deferred — future version)
- Native mobile app production store release (API/UX readiness only in current phase)
- Open marketplace for third-party content providers (deferred — future version)
- General-purpose CMS features outside LMS domain
- Multi-language UI (content is multilingual-ready via Drupal; UI strings are English-only in MVP)

## Constraints

| Type | Constraint | Implication |
|------|------------|-------------|
| Platform | Drupal 11.3.5 + PHP 8.3 | Entity API, Plugin system, Twig rendering, Drush 13 |
| Database | MariaDB 10.11 (utf8mb4_general_ci, InnoDB) | 202 tables; raw SQL used in analytics queries |
| Dev environment | DDEV (`everlms.ddev.site`, nginx-fpm) | All local dev and Drush commands run through DDEV |
| Module count | 27 `lms_*` modules + `open_switcher` (28 dirs total) | Module architecture is fixed; add capability inside existing modules unless a new domain clearly warrants a new module |
| Front-end stack | Bootstrap 5.3.3 (CDN), Dart Sass, no licensed UI framework | Skins built in SCSS; CDN dependency at runtime |
| Mobile | Flutter ≥3.0.1, Riverpod state management | Backend must maintain `/api/v1/*` contract |
| Budget / licensing | Composer open-source stack only | No commercial CMS add-ons or licensed PDF/video services |
