# U02-getting-started - Getting Started

## Web
1. Register/login at `/user/register` (you get the **student** role).
2. Browse `/courses`; open a course you like.
3. Enroll free, or buy via `/checkout/{course}` (card / bank transfer / PayPal / ZaloPay).
4. Start learning at your [dashboard](../../C-Design/C11-pages-components/pages/P017-dashboard.md) → open a lesson → mark complete.
5. Take the quiz; pass to earn a certificate (`/my-certificates`).

## Mobile (Flutter app)
1. Register in the app (you'll verify with an OTP code).
2. Log in (bearer token issued automatically).
3. Browse, enroll, learn, take quizzes — your progress syncs with the web.

## Tips
- Resume anytime from "My courses".
- Save interesting courses to your wishlist; add private notes while watching lessons.
