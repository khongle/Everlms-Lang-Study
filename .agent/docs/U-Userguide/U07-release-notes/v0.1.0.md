# Release Notes: v0.1.0 — Pre-release Scaffold

**Release date:** 2026-04-16
**Release type:** Pre-release / Scaffold
**Upgrade guide:** N/A (initial release)

> ⚠️ **Pre-release notice.** Version 0.1.0 là scaffold release cho internal stakeholder review. **Chưa production-ready.** Một số feature (payment gateway, AI) còn là stub — xem Known Issues.

## Highlights

- **Nền tảng Drupal 11 + PHP 8.3 + MariaDB 10.11** đã hoạt động với 26 `lms_*` modules + 1 utility.
- **29 entity classes** (28 content + 1 config) scaffolded cho tất cả domain: Content, Assessment, Progress, Commerce, Certificate, Communication, Gamification.
- **Course → Chapter → Lesson** flow hoạt động với 9 lesson types (video, text, quiz, h5p, scorm, pdf, pptx, zoom, mixed).
- **Assessment engine** với 8 question types + GradingStrategyFactory (ADR-005).
- **Progress cascade** (lesson → chapter → course) hoạt động cơ bản.
- **Theme** Bootstrap 5.3 dark premium (`lms_theme`) + alternative classic (`lms_classic`).

## New Features (Scaffolded)

### Course Management (FEAT-01)
Instructor có thể tạo course với cấu trúc C→Ch→L, upload 9 lesson types, publish/unpublish. Xem [instructor-01-create-course.md](../U03-feature-guides/instructor-01-create-course.md).

### Assessment (FEAT-02)
Quiz builder 8 question types với auto-grade (trừ essay). Xem [instructor-02-build-quiz.md](../U03-feature-guides/instructor-02-build-quiz.md).

### Learning Progress (FEAT-03)
Cascade automatic từ lesson → chapter → course. Dashboard `/my-learning`. Xem [learner-04-track-progress.md](../U03-feature-guides/learner-04-track-progress.md).

### Certificate (FEAT-06)
Auto-issue `UserCertificate` khi complete khóa eligible. PDF render qua dompdf. Public verify URL `/verify/{code}`. Xem [learner-05-earn-certificate.md](../U03-feature-guides/learner-05-earn-certificate.md).

### Communication (FEAT-08)
Forum (per-course + global), Notification (10 types), Note, Rating, FAQ entities. In-app bell + email digest options.

### AI Course Builder (FEAT-14) — Feature-flagged
`FF_FEAT_AI_BUILDER` default OFF. Hỗ trợ OpenAI, Gemini, Pollinations providers. Xem [instructor-03-ai-course-builder.md](../U03-feature-guides/instructor-03-ai-course-builder.md).
