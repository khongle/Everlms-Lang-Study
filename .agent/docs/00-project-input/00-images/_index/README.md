# 00-images Index

Searchable index for the canonical `01-base/00-images/all` image library.

Total image files indexed: **4774**

## Files

- `index.csv`: complete searchable table for every image under `all/`.
- `index.json`: JSON version of the same searchable rows.
- `catalog.md`: human-readable sample catalog grouped by collection and category.
- `object-overrides.json`: manual object annotations preserved from the preset source.
- `visual-imagery/`: visual-system maps copied from C10 imagery docs.

Important search columns: `file`, `folder_category_1`, `folder_category_2`, `source_collection`, `objects`, `alt`, `tags`, and `search_text`.
