# EverLMS — Wireframes

> Text-based wireframes mô tả chi tiết layout cho ~80+ pages.

## Design Rules

> [!IMPORTANT]
> - **Navigation:** Top horizontal navbar + mega-menu dropdown. **KHÔNG dùng left sidebar.**
> - **Theme:** Dark premium, blue/purple gradient accents, glassmorphism elements
> - **Responsive:** Desktop-first, breakpoints: 1200px / 992px / 768px / 576px
> - **Grid:** Bootstrap 5.3 (12-column)
