State with useState

React's useState hook is the foundation of interactive UIs. In this lesson you'll learn exactly how state works under the hood — why React re-renders only the components that need to update, and how to write state updates that are predictable and bug-free. We walk through a live coding session building a dynamic counter, a toggle switch, and a multi-field form, showing the pitfalls developers run into when starting out with state.

By the end you'll understand when to reach for useState versus other hooks, how to manage arrays and objects inside state correctly, and how to avoid the common stale-closure trap that trips up even experienced engineers. This knowledge unlocks everything that follows in the course.

In this lesson

  • How React detects state changes and schedules re-renders
  • Updating objects and arrays in state without mutation
  • The functional updater form: setState(prev => ...)
  • Derived state vs. redundant state: keeping your component clean
  • Live project: building a multi-step form with controlled inputs
