1.4 — Controllers & Views in Laravel

📖 Estimated reading time: 15 min 📅 Last updated: 2026-02-10 📊 Difficulty: Intermediate

What Is an MVC Controller?

In Laravel's Model-View-Controller architecture, a controller groups related request-handling logic into a single class. Instead of defining all your logic as closures in route files, controllers keep things organized and testable.

ℹ️
Tip — Single Responsibility
Each controller method should handle exactly one HTTP action. Thin controllers delegate heavy logic to service classes or actions.

Creating a Controller

Use the Artisan CLI to scaffold a new controller:

php artisan make:controller CourseController --resource

This generates a resource controller with the standard CRUD methods: index, create, store, show, edit, update, destroy.

Returning Views

A controller action typically returns a Blade view using the global view() helper:

public function show(Course $course): View
{
    return view('courses.show', [
        'course' => $course,
        'lessons' => $course->lessons()->published()->get(),
    ]);
}
⚠️
Watch Out — N+1 Queries
Always eager-load relationships in your controller rather than lazy-loading inside the view. Use with('lessons') or load() to avoid the N+1 problem.

Blade Templating Basics

Blade is Laravel's powerful templating engine. Key directives:

  • @extends('layouts.app') — inherits a master layout
  • @section('content') … @endsection — fills a slot
  • @foreach($items as $item) … @endforeach — iteration
  • {{ $variable }} — escaped output (XSS safe)
  • {!! $html !!} — raw output (use carefully)

Template Inheritance Example

{{-- resources/views/courses/show.blade.php --}}
@extends('layouts.app')

@section('title', $course->title)

@section('content')
  <h1>{{ $course->title }}</h1>
  @foreach($lessons as $lesson)
    <a href="{{ route('lesson.show', $lesson) }}">
      {{ $lesson->title }}
    </a>
  @endforeach
@endsection
✅
Best Practice — View Composers
Use View Composers (registered in a ViewServiceProvider) to share data across many views without passing it from every controller — great for nav menus, user data, etc.
