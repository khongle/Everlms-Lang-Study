What does the php artisan migrate command do in Laravel?
✅ Correct
▲
Your answer: Runs all pending database migrations
Explanation: php artisan migrate reads migration files in database/migrations/ that haven't been run yet and executes their up() methods, modifying the database schema accordingly.
2
Which Eloquent method returns the first matching record or throws a ModelNotFoundException?
✅ Correct
▶
Your answer: findOrFail()
Explanation: findOrFail($id) is identical to find() but throws a ModelNotFoundException instead of returning null when no record is found. Laravel's exception handler converts this into a 404 HTTP response by default.
3
Which Eloquent method retrieves the first matching record or creates it if it does not exist?
✅ Correct
▶
Your answer: firstOrCreate()
Explanation: firstOrCreate(array $attributes, array $values = []) searches for a record matching $attributes. If not found it creates and persists a new record combining $attributes and $values. Use firstOrNew() if you don't want automatic persistence.
7
In Laravel, which HTTP verb should be used to partially update a resource according to REST conventions?
❌ Wrong
▶
Your answer: PUT
Correct answer: PATCH
Explanation: REST conventions distinguish between PUT (replace the entire resource) and PATCH (apply a partial update). Laravel's resource controller maps PUT/PATCH /resources/{id} to the update() action, but semantically PATCH is the correct verb for partial updates. Both work in practice because Laravel accepts either verb for the update route.
10
Name two Artisan commands used during deployment to optimize a Laravel application.
⚡ Partial
▶
Your answer: php artisan config:cache, php artisan route:cache
Also accepted: php artisan view:cache, php artisan optimize
Explanation: config:cache merges all config files into a single cached file, and route:cache compiles all routes into a serialized cache, both dramatically reducing bootstrap time. php artisan optimize (Laravel 11+) runs several of these in one step.
