1.3 — Introduction to Laravel Routing

Learn how Laravel's router maps URIs to controller actions and how route parameters, named routes, and middleware groups work.

About This Lesson

In this video lesson you will explore the heart of the Laravel request lifecycle — the router. We cover:

  • Defining routes in routes/web.php and routes/api.php
  • Route parameters and optional segments
  • Named routes and URL generation with route()
  • Route groups, prefixes, and middleware
  • Resource controllers and RESTful conventions

By the end you'll be able to confidently structure your application's URL space.
