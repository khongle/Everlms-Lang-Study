State with useState

The useState hook is how a function component remembers information between renders. Calling it returns a pair: the current value and a setter function. Whenever you call the setter, React schedules a re-render with the new value in place — you never mutate the variable directly.

A component can call useState as many times as it needs, and each call keeps its own independent slot of state. This is what lets a single component track several unrelated pieces of UI state — a counter, a form field, a toggle — without stepping on each other.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}

Notice that setCount(count + 1) reads count from the current render's closure. When you need to update state based on the previous value reliably — for example inside an event handler that might fire multiple times — pass an updater function instead: setCount(c => c + 1).

  • State is isolated per component instance. Two renders of the same component keep separate state.
  • Updates are batched. Multiple setState calls inside one event handler trigger a single re-render.
