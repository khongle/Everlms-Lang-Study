## Implementation status (as of 2026-06-20)

**as-built (profile, certificates); orders are managed via workspace not user portal.**

- Profile: `/profile` → `UserPortalController::profile` → `lms-profile.html.twig`. Note: `profile()` loads the user entity in 'full' view mode; this route is defined but the method body indicates it may be lightly scaffolded.
- My Certificates: `/my-certificates` → `UserPortalController::myCertificates` → `lms-my-certificates.html.twig`. Lists all `lms_user_certificate` entities for current user with PDF download links. Public certificate verify: `/certificate/verify` (form-based, public). Certificate PDFs generated by `CertificateGenerator` using mPDF — **fully implemented**.
- Orders: **no `/my-orders` user-facing route exists**. Learners can view bank-transfer instructions at `/checkout/bank-transfer/{order}`. Admin manages orders at `/workspace/orders`. This is a gap vs. the wireframe.
- Membership: `/my-membership` → `MembershipController::myMembership` → `lms-my-membership.html.twig`. Cancel = disables auto-renew (`field_auto_renew=FALSE`). Auto-renewal via webhook is **not implemented**.
