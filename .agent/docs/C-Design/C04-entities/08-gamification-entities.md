# C04 — Entities: Gamification (lms_badge, lms_user_badge)

**Owner module:** [`lms_badge`](../C05-modules/lms_badge.md)
**Mode:** as-built
**Description:** Badge catalog (editorial) and user badge award records (transactional). Both entities are schema-complete but carry **zero live data**: the badge award logic — criteria evaluation, event subscribers, and services — is entirely absent from the codebase. The module is a near-stub.

- No service, cron job, or event subscriber exists that creates `lms_user_badge` rows.

- `field_awarded_at` uses the `created` field type and is auto-populated on entity save.
