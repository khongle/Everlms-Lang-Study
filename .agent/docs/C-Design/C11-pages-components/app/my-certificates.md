# My Certificates — `/my-certificates`

Lists all certificates earned by the authenticated learner. Each entry shows the certificate visual (or summary card), course name, issue date, score, and actions (Download PDF, Print, Share). Rendered by `UserPortalController::myCertificates()`.

## Certificate Issuance Flow (background, not on this page)

Certificates are **not** issued from this page. They are auto-issued by an event subscriber in `lms_certificate` on `QuizPassedEvent::EVENT_NAME`:

1. `lms_quiz` dispatches `QuizPassedEvent` when a quiz result reaches passing score.
2. `lms_certificate` event subscriber receives the event; traverses `lms_quiz → lms_lesson → lms_chapter → lms_course` to find the parent course.
3. Checks that the course has a `field_certificate_template` set.
4. Creates `lms_user_certificate` entity; generates PDF via mPDF using `certificate-pdf.html.twig` template.
5. The new certificate then appears on this page at next load.

For admin management of issued certificates, see `/workspace/certificates` (`lms_certificate.admin_dashboard`).
