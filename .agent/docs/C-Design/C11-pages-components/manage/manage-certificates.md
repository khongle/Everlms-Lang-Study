# C11 — Page: Manage Certificates

**Canonical URL:** `/workspace/certificates` *(per [`../C07-sitemap.md`](../../C07-sitemap.md))*
**Route name:** `lms_certificate.admin_dashboard`
**Solution:** Custom controller (`CertificateAdminController::adminDashboard`) renders `lms_admin_certificates` Twig template. Related sub-pages: template management at `/workspace/certificate-templates`, PDF regeneration at `/workspace/certificates/{id}/regenerate`, revocation at `/admin/lms/certificates/{id}/revoke`. Certificates are auto-issued by `CertificateEventListener` on `lms_quiz.passed` event; PDF generated by `CertificateGenerator` using mPDF.
**Owner module:** [`lms_certificate`](../../C05-modules/lms_certificate.md)
**Primary source:** `entity:lms_user_certificate`
**Editable source:** `entity:lms_certificate_template` — fields: `name`, `field_body`, `field_design`, `field_background`, `field_signature`, `field_logo`, `field_seal`, `field_orientation`, `field_layout`, `field_color_scheme`, `status`; `entity:lms_user_certificate` — `field_revoked`, `field_revoke_reason` (via revoke form)
**Editor role:** Administrator
**Editor management UI:** `/workspace/certificates` (issued list), `/workspace/certificate-templates` (template CRUD), `/workspace/certificates/{id}/regenerate` (PDF regen), `/admin/lms/certificates/{id}/revoke` (revoke)
**Revision / moderation:** Not revisionable.
**Forms:** `RevokeCertificateForm` (at `/admin/lms/certificates/{id}/revoke` — requires `revoke any certificate` permission); `VerificationForm` (public, at `/certificate/verify`); `CertificateTemplateForm` (entity form for templates)
**Theme template:** `lms_certificate/templates/lms-admin-certificates.html.twig` (dashboard); `lms_certificate/templates/lms-admin-certificate-templates.html.twig` (template list); `lms_certificate/templates/certificate-pdf.html.twig` (PDF layout, rendered by mPDF)
**Access:** Role-gated: `administer lms_course` (dashboard, templates, regen); `revoke any certificate` (revoke form at `/admin/*`)
**Cache:** Per-user; no anonymous caching. Invalidated on `lms_user_certificate` save/delete.
**Translation:** Monolingual EN
**Related entities:** [`lms_user_certificate`](../../C04-entities/01-content-entities.md), [`lms_certificate_template`](../../C04-entities/01-content-entities.md), [`lms_course`](../../C04-entities/01-content-entities.md), [`lms_quiz_result`](../../C04-entities/01-content-entities.md)
**Prototype reference:** None — no dedicated C10 prototype exists for this page.
**Notes:** Certificate issuance is fully automatic: `CertificateEventListener::onQuizPassed` subscribes to `lms_quiz.passed`, traverses Quiz → Lesson → Chapter → Course to find the course, calls `CertificateManager::checkAndIssueCertificate`. PDF is generated by `CertificateGenerator` using `mpdf/mpdf` (Composer). If mPDF is missing, generator logs error and returns NULL (graceful degradation). `field_expiry_date` on `lms_user_certificate` is of type `datetime` (date-only) — **known bug**: originally varchar (raw storage type mismatch noted in codebase). Template `field_layout` is a raw Twig/HTML string — "Input the full HTML/Twig structure" — meaning template customization is code-level, not WYSIWYG. Secrets risk: `«secret in config — see security risk»` for any signing keys if applicable (certificate generation uses no external signing keys). Tokens: `[student_name]`, `[course_name]`, `[issue_date]` in `field_body`.

- **Notes:** `RevokeCertificateForm` extends `ConfirmFormBase`. `CertificateAdminController::regenerateCertificate` blocks regeneration if `field_revoked=TRUE`.
