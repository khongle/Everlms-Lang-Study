## Scope

Implements the full quiz engine for EverLMS learners:

- Three content entities: `lms_quiz` (the quiz definition), `lms_quiz_result` (a learner attempt record), `lms_question_response` (per-question graded record).
- A static factory + strategy pattern grading system covering all 8 question types; no Drupal Plugin API involved.
- `QuizController`: four learner-facing routes (take quiz, submit, view result, my results dashboard).
- `QuizPassedEvent`: dispatched on pass; consumed by `lms_certificate` and `lms_notification`.
- Admin CRUD routes auto-generated by `AdminHtmlRouteProvider`.
- Three Twig templates (dark glassmorphism; inline styles + Font Awesome CDN).
- `hook_theme()` registration + `lms_quiz_update_10001` update hook.

Full design: [`../C-Design/C05-modules/lms_quiz.md`](../../C-Design/C05-modules/lms_quiz.md)

## Notes

### Known Bugs (as-built)

| ID | Severity | Description |
|----|----------|-------------|
| BUG-QUIZ-01 | Medium | `field_start_time` on QuizResult hardcoded to `request_time - 60`; actual quiz duration is not tracked |
| BUG-QUIZ-02 | Medium | `lms-quiz-result.html.twig` uses `score >= 70` as pass/fail display; ignores `field_threshold` |
| BUG-QUIZ-03 | Low | No concurrent-submit guard; double-submit can create two QuizResult entities for one attempt |

### Technical Debt

| ID | Severity | Description |
|----|----------|-------------|
| DEBT-QUIZ-01 | Low | All auto-graded strategies strictly binary; no partial credit for MultipleChoice/Ordering/Matching |
| DEBT-QUIZ-02 | Low | No manual-grading workflow UI for essay responses (`pending_review=TRUE` has no teacher dashboard) |
| DEBT-QUIZ-03 | Low | Templates embed large inline `<style>` blocks and load Font Awesome 6.4.0 from CDN |

### Architecture Note

The grading subsystem is a **static PHP factory + strategy pattern** — not a Drupal Plugin API. `GradingStrategyFactory::getStrategy(string $bundle)` is called directly from `QuizController::submitQuiz()` with no service container involvement. This is intentional (performance, simplicity) but means strategies cannot be overridden via contrib without patching the factory.

See `../C-Design/C05-modules/lms_quiz.md` for complete entity field tables, controller flow, and grading strategy matrix.
