# Content Tools — Sample Data Seeder

> Thư mục này sẽ chứa specs cho content tools: sample data seeder, data generator, demo content.

## Planned Content

### Sample Data Strategy

- [ ] Sample chapters & lessons (3-5 chapters/course, 3-8 lessons/chapter)
- [ ] Sample quizzes với tất cả 8 question types
- [ ] Sample users (admin, manager, instructors, students)
- [ ] Sample orders & memberships
- [ ] Sample certificates
- [ ] Sample ratings & reviews

### Drush Commands
- `drush everlms:seed` — Tạo toàn bộ sample data
- `drush everlms:seed:courses` — Chỉ tạo courses
- `drush everlms:seed:users` — Chỉ tạo users
- `drush everlms:clean` — Xoá sample data
