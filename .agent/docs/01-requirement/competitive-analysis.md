## 3. Competitive Positioning

### EverLMS Strengths (Lợi thế cạnh tranh)

| # | Strength | So với đối thủ |
|---|----------|----------------|
| 1 | **8 Question Types** | Thinkific (3), Teachable (2), Kajabi (1) chỉ có basic quiz |
| 2 | **SCORM + H5P** | Thinkific, Teachable, Kajabi không hỗ trợ |
| 3 | **Self-hosted + SaaS** | Toàn quyền data, không phụ thuộc vendor. Thinkific/Teachable/Kajabi lock-in |
| 4 | **0% Transaction Fees** | Teachable thu 7.5-10% trên plan thấp |
| 5 | **One-time License** | Đối thủ SaaS: $36-$399/mo recurring vĩnh viễn |
| 6 | **Certificate Verification** | Public URL verify — unique feature, đối thủ không có |
| 7 | **3-level Progress** | Course/Chapter/Lesson — đối thủ SaaS chỉ track course level |
| 8 | **Drupal Enterprise** | Security, multilingual, entity architecture — enterprise-grade |
| 9 | **7 Roles System** | Granular hơn Thinkific (2), Teachable (3), Kajabi (2) |
| 10 | **FAQ 3-scope** | Global/Course/Lesson FAQ — không đối thủ nào có |

### EverLMS Gaps (Cần cải thiện)

| # | Gap | Đối thủ đã có |
|---|-----|---------------|
| 1 | **Native Video Hosting** | Thinkific, Teachable, Kajabi host video trực tiếp |
| 2 | **AI Subtitles/Translation** | Teachable, Kajabi có AI subtitle generation |
| 3 | **Built-in Email Marketing** | Kajabi tích hợp email marketing + automation |
| 4 | **Sales Funnels** | Kajabi: landing pages, upsells, downsells |
| 5 | **In-app Purchase (Mobile)** | Teachable: native iOS/Android với offline mode |
| 6 | **Abandoned Cart Email** | Thinkific, Teachable, Kajabi recover lost sales |
| 7 | **Podcast Hosting** | Kajabi tích hợp podcast |
| 8 | **Branded Mobile App** | Kajabi Pro: branded app riêng |
| 9 | **Code Playground** | Codecademy-style in-browser editor chưa có |
| 10 | **Interactive Video** | Hotspots, embedded quiz trong video |

## 4. Market Positioning Matrix

```
                    ┌─────────────────────────────────────────┐
                    │              ENTERPRISE                  │
                    │                                          │
              ✅ Moodle     ✅ Canvas                         │
                    │                                          │
                    │         ⭐ EverLMS                       │
       OPEN ────────┼────────────────────────────── CLOSED    │
                    │                                          │
              ✅ LearnDash                                    │
                    │    ✅ Thinkific  ✅ Teachable            │
                    │              ✅ Kajabi                   │
                    │              CREATOR                     │
                    └─────────────────────────────────────────┘
```

> **EverLMS** nằm ở vị trí **Enterprise + Open** — tương tự Moodle nhưng với UX hiện đại và commerce tích hợp sẵn. Đây là gap lớn trên thị trường vì:
> - Moodle: Enterprise nhưng UX cũ, không có commerce
> - Thinkific/Teachable/Kajabi: UX đẹp nhưng closed, không enterprise
> - LearnDash: WordPress, giới hạn scalability
