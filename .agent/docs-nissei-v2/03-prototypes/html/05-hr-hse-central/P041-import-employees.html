Why this screen is the point of the pageDirty master data is the main risk of any import: a duplicate code corrupts one employee’s history, an unknown branch or job role silently drops obligations from the training matrix, and a format mismatch breaks downstream certificate numbering. Nothing is written to the system until every error above is resolved. This reconciliation step exists so bad rows are caught here, not discovered months later as a missing certificate or a phantom employee.
