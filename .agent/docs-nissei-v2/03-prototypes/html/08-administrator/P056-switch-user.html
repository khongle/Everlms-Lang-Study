Switch user

Break-glass access: temporarily act as any account on this deployment, including the Nissei Administrator. Stricter than day-to-day support impersonation, and used rarely.

Break-glass, not routine support. This is the platform team’s emergency path into Nissei’s deployment, not a daily tool. It requires a reason and a ticket reference before the switch happens, is time-boxed and ends itself, notifies Dang Minh Tuan (Nissei Administrator) by email the moment it starts, and can reach any account including the Nissei Administrator’s own. The full session is written to the audit log, event type Break-glass. Always switch back when you are done.

Why this is separate from day-to-day impersonation The Nissei Administrator has their own switch user for daily support: reason only, employee accounts only. This surface exists because the platform team occasionally needs more, and needs it to be visibly harder to use: a ticket reference in addition to a reason, a session that times out on its own, a mandatory notification to the customer the moment it starts, and reach that extends to the Nissei Administrator account itself, which the customer’s own tool cannot touch. Keeping the two apart means the rare, high-privilege path is never the convenient one.
