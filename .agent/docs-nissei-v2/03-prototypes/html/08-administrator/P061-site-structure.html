Site structure

What the product core is built from: entity types, fields, views, menus and themes. Read-only here. Structure changes ship as a release, see Modules and updates, and are validated in staging before they reach production.

Hand-editing structure in production is what causes drift. Adding a field, changing a view or renaming a menu link directly on this environment, outside a packaged release, is exactly the failure mode Configuration sync exists to catch. It has happened once already, from a break-glass session on 09 Jul 2026: see that page for the item still pending reconciliation.
