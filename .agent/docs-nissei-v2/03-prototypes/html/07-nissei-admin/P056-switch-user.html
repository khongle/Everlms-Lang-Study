Temporarily browse the system as another employee to diagnose a support ticket. Every switch requires a written reason and is recorded permanently.

About impersonation. Switching lets you see exactly what an employee sees, to resolve issues that cannot be diagnosed from their record alone. A reason is required before the switch happens, a red banner marks every page while it is active, and the full session (who, whom, when, why, and how long) is written to the audit log. Always switch back when you are done.
